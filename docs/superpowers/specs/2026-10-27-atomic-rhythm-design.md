# Atomic Rhythm — дизайн v1

Дата: 2026-10-27
Статус: на ревью

## 1. Цель

Одностраничное веб-приложение, которое по заданной молекуле (или атому)
генерирует ритмические паттерны. Химические свойства (протоны, нейтроны,
электроны, оболочки, валентность, связи, кольца, возбуждение) через
настраиваемую матрицу модуляции превращаются в ритм. Результат
проигрывается в браузере, визуализируется и экспортируется в Strudel и MIDI.

### Ограничения

- Одна страница: HTML + TypeScript + CSS.
- Никаких демонов, серверов, занятых портов. Итоговый артефакт —
  один `dist/index.html`, открываемый через `file://`.
- Сборка разовая: Vite + `vite-plugin-singlefile`. Dev-сервер не обязателен
  для использования (разработчик может запускать его по желанию).
- Данные таблицы Менделеева вшиты в бандл (TS-модуль). Пользовательские
  данные — в IndexedDB. SQLite не используется (не нужен SQL, а `.wasm`/`.db`
  через `file://` загрузить нельзя).

### Вне объёма v1

Мелодические линии, внешние воздействия кроме нагрева, экспорт WAV,
Web MIDI в реальном времени, визуальный редактор молекул, 3D-визуализация.
Архитектура обязана не мешать их добавлению (см. §4 IR и §5 маппинг).

## 3. Химическая модель (`src/chem/`)

Чистые функции, без DOM и звука.

### 3.1 Данные элементов (`elements.ts`)

118 записей: `symbol, name, Z, atomicMass, mostAbundantA, group, period,
block (s|p|d|f), electronegativity (Pauling | null), ionizationEnergy1 (эВ)`.

### 3.2 Атом (`atom.ts`)

Вход: элемент, массовое число `A` (по умолчанию `mostAbundantA`), заряд
(по умолчанию 0). Выход:

- `protons = Z`, `neutrons = A − Z`, `electrons = Z − charge`;
- электронная конфигурация по правилу Клечковского (без исключений
  вида Cr/Cu в v1 — упрощение, отмечено в коде):
  оболочки `shells: number[]` (например Na → `[2, 8, 1]`) и подоболочки;
- `valenceElectrons` — электроны внешней оболочки;
- `typicalValence` — по группе (для главных подгрупп), иначе из таблицы
  исключений; используется в ритме, не для валидации химии.

Изотопы: H → протий (1p 0n 1e), `[2H]` дейтерий (1p 1n 1e),
`[3H]` тритий (1p 2n 1e). Ионы меняют только число электронов.

### 3.3 Молекула (`molecule.ts`, `smiles.ts`)

Граф: `atoms[]` (элемент, A, заряд, aromatic) и `bonds[]` (a, b, order
1|2|3, aromatic). Неявные водороды разворачиваются в явные атомы-узлы
(H₂O = 3 атома).

Парсер SMILES (подмножество):
- органическое подмножество `B C N O P S F Cl Br I`, ароматические
  `b c n o p s`;
- скобочные атомы `[изотоп Символ Hn заряд]`, например `[2H]`, `[Na+]`,
  `[NH4+]`;
- связи `- = # :`, ветви `( )`, замыкания колец `1-9` и `%nn`;
- `.` — несвязанные компоненты (ионные соединения: `[Na+].[Cl-]`);
- стереосимволы `@ / \` игнорируются.
- Ошибка разбора → исключение `SmilesError` с позицией символа; UI
  показывает сообщение и подсвечивает позицию.

### 3.4 Анализ (`analysis.ts`)

- **Кольца:** минимальный набор циклов (SSSR) — размер, атомы,
  ароматичность (все атомы ароматические).
- **Функциональные группы:** OH, NH₂, C=O, COOH (сопоставление шаблонов
  по графу).
- **Тип связи** по Δχ: `< 0.4` — неполярная ковалентная,
  `0.4–1.7` — полярная ковалентная, `> 1.7` или заряженные ионы в разных
  компонентах — ионная. Если χ отсутствует — неполярная ковалентная.
- **Порядок обхода:** DFS от первого атома SMILES; задаёт
  последовательность атомов в последовательном режиме.

## 4. Ритмический IR (`src/rhythm/ir.ts`)

Время в тиках: `PPQ = 96` (шестнадцатая = 24 тика, восьмая = 48).

```ts
type VoiceId = string; // 'proton', 'neutron', 'electron.s1', 'bond', 'motif.ring6', ...
interface RhythmEvent {
  tick: number;          // позиция внутри цикла дорожки
  velocity: number;      // 0..1
  durationTicks: number;
  articulation: 'normal' | 'ghost' | 'flam' | 'roll' | 'fill';
  atomIndex?: number;    // для подсветки в визуализации
}
interface Track {
  voice: VoiceId;
  cycleTicks: number;    // длина цикла; разные cycleTicks = полиметрия
  events: RhythmEvent[];
}
interface Pattern {
  timeSignature: [number, number]; // основной размер, по умолчанию 4/4
  bars: number;                    // длина паттерна в тактах
  tracks: Track[];
}
```

IR ничего не знает об инструментах — это даёт переназначение и будущие
мелодии.

## 5. Матрица модуляции и маппинг (`src/rhythm/modmatrix.ts`, `src/mapping/`)

### 5.1 Матрица модуляции

Маршрут: `{ source, dest, voice, transform }`.

- **source:** `protons | neutrons | electrons | electronsInShell(i) |
  shellCount | period | group | valenceElectrons | typicalValence |
  electronegativity | bondOrder | bondDeltaChi | ringSize | atomicMass |
  ionizationEnergy`.
- **dest:** `hits (k) | steps (n) | rotation | velocity | swing |
  articulation | barLength`.
- **transform:** `identity | mod(n) | clamp(min,max) | scale(inMin,inMax,outMin,outMax) | round`.

Рецепт по умолчанию (соответствует исходному ТЗ):

| voice | dest | source |
|---|---|---|
| proton | hits | protons |
| neutron | hits | neutrons |
| electron.s{i} | hits | electronsInShell(i) |
| proton, neutron | steps | константа 16 |
| electron.s{i} | steps | сетка оболочки (§6.1) |
| electron.s{i} | rotation | steps / 2 |
| все | velocity | scale(group, 1..18 → 0.6..1.0) |

Рецепты сохраняются и загружаются из IndexedDB.

### 5.2 Маппинг голос → выход

Таблица `VoiceId → { synthVoice, midiNote, strudelSound }`, редактируемая
в UI. По умолчанию (GM drums, канал 10):

| voice | synth | MIDI | Strudel |
|---|---|---|---|
| proton | kick | 36 | bd |
| neutron | closed hat | 42 | hh |
| electron.* | snare | 38 | sd |
| bond | clap | 39 | cp |
| motif.* | rim / perc | 37 | rim |

Слой спроектирован так, чтобы позже добавить маппинг голос → нота
(мелодии) без изменения IR.

## 6. Ритмический движок (`src/rhythm/`)

### 6.1 Паттерн атома (`atom-pattern.ts`)

Каждый голос — евклидов ритм `E(k, n, rotation)` (алгоритм Бьорклунда,
`euclid.ts`), параметры — из матрицы модуляции.

- Если `k > n`: в сетку ставится `n` ударов (все шаги), излишек повышает
  velocity: `velocity = min(1, base × (1 + (k − n) / n))`. Других
  эффектов нет. `k = 0` → дорожка молчит.
- Сетки оболочек (в шестнадцатых): s1 = 16, s2 = 12, s3 = 20, s4 = 24,
  s5 = 28, s6 = 32, s7 = 36. Тяжёлые атомы дают полиритмию.
- Пример H (протий): proton `E(1,16)`, neutron пусто,
  electron.s1 `E(1,16, rot 8)` → кик на 1, снейр на 3.

### 6.2 Паттерн молекулы (`molecule-pattern.ts`)

Режим переключается в UI:

1. **Последовательный** (по умолчанию): атомы в порядке DFS, по
   `atomsPerBar` (по умолчанию 2) атомов на такт; каждый атом занимает
   сегмент `16 / atomsPerBar` шагов, его голоса строятся в этом сегменте.
   `bars = ceil(atoms / atomsPerBar)`. H₂ → 1 такт: H | H.
2. **Наложение:** паттерны всех атомов на одной сетке; совпадающие
   удары одного голоса объединяются (velocity = max).

**Связи** — артикуляция на границе сегментов двух соседних атомов,
событие в голосе `bond`:
- одинарная → один удар на первом шаге следующего сегмента;
- двойная → `flam`;
- тройная → `roll` (три удара на последних двух шагах предыдущего
  сегмента);
- ароматическая → `normal` с velocity 0.5 (кольцо выражается мотивом);
- ионная → весь сегмент следующего атома сдвигается на 1 шаг (свинг).

### 6.3 Важные паттерны / мотивы (`motifs.ts`)

Декларативная таблица `{ match, build }`; новые мотивы добавляются без
правки движка.

- Кольцо размера `r`: дорожка `motif.ring{r}` с циклом `r` восьмых
  (полиметрия к 4/4). Ароматическое: удары на всех `r` восьмых, акценты
  (velocity 1.0) на 1-й и `r/2+1`-й (бензол → 6/8 с акцентами на 1 и 4).
  Неароматическое: `E(ceil(r/2), r)`.
- Функциональные группы — короткие мотивы в голосе `motif.group`, один
  раз в начале каждого цикла паттерна: OH — 2 удара, NH₂ — 3, C=O — 1
  акцент, COOH — 4.

### 6.4 Возбуждение (`excitation.ts`)

- UI-параметр **температура** `T ∈ [0, 100]`.
  `BPM = baseBpm × (1 + T / 100)`.
- Порог атома: `threshold = 100 × (IE1 − 3.5) / (20 − 3.5)`.
  Cs ≈ 2, Na ≈ 8, H ≈ 61, He и Ne > 100 (не возбуждаются в диапазоне).
- `T ≥ threshold` → атом возбуждён: один внешний электрон переходит на
  оболочку `shellCount + 1` (его удары переезжают на сетку этой
  оболочки), и на последнем такте каждой фразы (`phraseBars`, по
  умолчанию 4) атом играет филл (`articulation: 'fill'`, удвоенная
  плотность его голосов электронов).
- `T < threshold` → релаксация: на следующей границе фразы электрон
  возвращается.
- Приближение: энергия возбуждения заменена первой энергией ионизации.

### 6.5 Форма (`form.ts`)

Переключатель «старт с молекулы» / «сборка»:

- **Сборка:** интро — каждый уникальный элемент молекулы по 1 такту
  (паттерн одиночного атома) → сборка: `buildBars` (по умолчанию 4) тактов,
  голоса паттерна молекулы входят по одному → основной луп.
- **Старт с молекулы:** сразу основной луп.

### 6.6 Планировщик и синтез (`src/audio/`)

- Look-ahead scheduler: таймер 25 мс, горизонт 100 мс, события
  ставятся по `AudioContext.currentTime`.
- Синтез: kick (синус с падением частоты), snare (шум + тон), hat
  (фильтрованный шум), clap, rim. Артикуляции: flam — предудар −15 мс
  с velocity × 0.5; roll — 3 удара за 2 шага.
- Смена BPM/температуры/маппинга применяется на следующей шестнадцатой.

## 7. Экспорт (`src/export/`)

- **Strudel:** `stack(...)` из дорожек; каждая дорожка — мини-нотация
  из её шагов (`s("bd ~ ~ ~ ...")`), цикл Strudel = 1 такт,
  полиметрия через `.slow(cycleSteps / 16)`, velocity через `.gain("...")`.
  Код копируется в буфер обмена.
- **MIDI:** собственный писатель SMF type 1, PPQ 96, канал 10, одна
  MIDI-дорожка на голос, длина = полный цикл формы (не менее НОК циклов
  дорожек, ограничено 64 тактами). Скачивание `.mid` через Blob.

## 8. Визуализация (`src/viz/`)

- **Раскладка:** у пресетов координаты заданы вручную; для SMILES —
  кольца правильными многоугольниками, затем силовая раскладка
  (200 итераций, детерминированная — фиксированный seed).
- **Атом:** круг с символом, подпись `p/n/e` под ним, валентные
  электроны точками по кругу (Льюис), заряд надстрочно. Переключатель
  «скрыть H».
- **Связь:** 1/2/3 линии; ароматическая — круг внутри кольца; подпись
  типа связи и Δχ при наведении.
- **Кольца:** подсветка с подписью мотива («бензол → 6/8»).
- **Синхронизация со звуком:** атом, чей сегмент/событие звучит,
  подсвечивается; возбуждённый атом светится, рисуется доп. оболочка
  с электроном.
- **Сетка секвенсора** под схемой: строки — голоса, столбцы — шаги,
  бегущий курсор; дорожки с другим циклом показывают свою длину.

## 9. UI

Тёмная тема, одна страница:

- слева — выбор пресета, поле SMILES, изотоп/заряд для одиночного атома;
- центр — SVG-молекула, под ней сетка секвенсора;
- справа — матрица модуляции, маппинг голосов, рецепты;
- сверху — транспорт: Play/Stop, base BPM, температура, режим
  (последовательный/наложение), форма (сборка/старт), `atomsPerBar`,
  экспорт Strudel / MIDI.

Пресеты: H, D, T, H₂, O₂, N₂, H₂O, CO₂, CH₄, NH₃, NaCl, этанол, уксусная
кислота, циклопентан, бензол, пиридин, кофеин.

## 10. Хранилище (`src/storage/`)

IndexedDB `atomic-rhythm`, хранилища `recipes` (матрица + маппинг) и
`patterns` (SMILES + настройки). Ошибка IndexedDB (например, приватный
режим) → предупреждение в UI, приложение работает без сохранения.

## 11. Тестирование

- Vitest, юнит-тесты для всех модулей `chem`, `rhythm`, `export`.
- Золотые тесты: H, D, T, H₂, H₂O, NaCl, бензол — ожидаемые дорожки IR.
- Strudel/MIDI: снапшоты вывода; MIDI — проверка заголовков и
  дельта-времён.
- Ручная проверка: `npm run build`, открыть `dist/index.html` через
  `file://`, проиграть пресеты.

## 12. Скилл проекта

`.agents/skills/atomic-rhythm-mapping/SKILL.md` — правила перевода химии
в ритм (рецепт по умолчанию, сетки оболочек, связи, мотивы, возбуждение),
чтобы любой агент генерировал и расширял паттерны единообразно.
Обновляется при каждом изменении правил маппинга.
